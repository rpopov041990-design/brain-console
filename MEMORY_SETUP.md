# Память: подключить существующую или создать свою

## Что именно мы называем памятью

| Компонент | Назначение | Чего он не делает |
|---|---|---|
| Реестр JSON | Агенты, команды, роли и маршруты | Не хранит полноценную историю разговоров |
| Neo4j | Хранилище узлов и связей | Самостоятельно не извлекает знания из чатов |
| Graphiti | Добавление эпизодов, извлечение и поиск фактов | Не получает доступ к ChatGPT автоматически |
| Brain Console | Просмотр реестра и графа | Не пишет память и не запускает агентов |
| Память ChatGPT | Персонализация внутри продукта | Не является готовой копией базы Graphiti |

Источники проекта, утверждённые общие уроки и импорт ChatGPT должны оставаться различимыми. Служебный статус «подключено» не доказывает, что факты записываются или используются агентом.

## Маршрут A — память уже есть

1. Определите владельца базы, адрес, имя базы и группы. Не создавайте вторую «главную» копию и не копируйте живую БД как обычную папку.
2. Подготовьте согласованную резервную копию средствами базы. Получите учётную запись для чтения; секреты держите в защищённом хранилище/окружении процесса.
3. Проверьте реестр локально:

   ```sh
   python3 memory_check.py --registry /your/private/task-personas.json
   ```

4. Задайте переменные `NEO4J_URI`, `NEO4J_USER`, `NEO4J_DATABASE`, `NEO4J_PASSWORD` и установите Neo4j Python Driver по README. Затем выполните проверку без записи:

   ```sh
   python3 memory_check.py --registry /your/private/task-personas.json --neo4j
   ```

   Программа выводит только результаты проверки и количества, не пароль, тексты эпизодов или имена людей. Отсутствие ожидаемой группы — предупреждение о несовместимости/пустой памяти, не команда миграции.

5. Запустите `server.py --live --registry /your/private/task-personas.json`. Найдите один заранее известный узел, откройте его связь и сверьте с источником. Отдельно откройте общее развитие: проектные данные не должны попадать туда.
6. Если текущие группы и метки отличаются от `codex-pinned` / `codex-global` и схемы DATA_FORMAT.md, адаптируйте чтение в отдельной ветке. Не переименовывайте рабочую базу ради интерфейса.

## Маршрут B — памяти ещё нет

1. Сначала запустите демо из README. Оно не требует базы и показывает только вымышленные данные.
2. Создайте **свой** реестр по DATA_FORMAT.md в `private/task-personas.json` или вне репозитория. Начните с одного настоящего агента; не копируйте чужие имена и ID. Для пустого реестра используйте `{"personas":{}}` — это допустимый, но ещё не наполненный источник.
3. Установите Neo4j по [официальной инструкции](https://neo4j.com/docs/desktop/current/installation/), создайте отдельную локальную базу и задайте собственный пароль. Не используйте демонстрационные пароли из примеров. Не публикуйте сетевой порт базы.
4. Выберите фиксированную версию Graphiti и следуйте [официальному MCP-руководству](https://github.com/getzep/graphiti/blob/main/mcp_server/README.md). Настройте именно провайдер Neo4j: не предполагайте, что он выбран по умолчанию. Укажите подходящие LLM и embeddings. Выбор облачного провайдера может передавать ему содержимое эпизодов и иметь отдельную стоимость; согласуйте это до импорта личных данных. Локальный провайдер тоже нужно проверить на совместимость.
5. Инициализируйте индексы штатным способом выбранной версии. Не запускайте команды очистки базы. [Официальный quickstart](https://github.com/getzep/graphiti/blob/main/examples/quickstart/quickstart_neo4j.py) показывает добавление эпизода и поиск; это пример API, а не полностью готовая установка нашей системы.
6. Подключите сервис памяти к выбранному агенту через поддерживаемый им MCP/SDK. Правило в промпте само по себе не создаёт подключение. Проверьте, что агент действительно видит инструменты поиска и записи.
7. Пройдите тест ниже, затем подключите Brain Console по маршруту A.

Эти шаги выполняет владелец новой установки. Комплект не устанавливает Neo4j/Graphiti, не создаёт учётные записи и не меняет настройки агента автоматически.

## Приёмочный тест: запись → поиск → использование → визуализация

1. В отдельной тестовой группе создайте через Graphiti один синтетический эпизод: «Тестовый проект использует контрольный цвет индиго», с уникальным ID проверки. Не используйте персональные данные.
2. Если сервис поставил запись в очередь, дождитесь подтверждения завершения. Ответ «queued» ещё не доказывает наличие фактов.
3. Найдите эпизод/факт инструментом поиска и проверьте ID, группу и исходный текст. Повторный поиск должен вернуть тот же факт, а не новую запись.
4. В новом контексте попросите агента назвать контрольный цвет **с указанием источника**. Проверьте факт обращения к памяти, не только правильный ответ из текущей переписки.
5. Для проверки карты используйте тестовую установку с поддерживаемыми группами и схемой. Произвольная тестовая группа в текущем интерфейсе не показывается. Чатовые сущности можно искать через «Память»; появление отдельного агента требует записи в реестре/структурной схемы.
6. Проверьте время обновления и источник связи. После добавления новой связи штатным источником она должна появиться на следующем обновлении карты.
7. Удаление теста выполняйте штатным инструментом по конкретному ID и только после подтверждения владельца. Не используйте массовый `clear`.

## Диагностика

| Симптом | Проверка |
|---|---|
| Демо открывается, своих данных нет | Демо специально изолировано; нужен явный live-режим |
| База доступна, узлов 0 | Проверьте имя базы, группу, завершение записи; это не ошибка сети |
| Узлы есть, факты не находятся | Проверьте индексы, embeddings, группу и текст запроса |
| В реестре агент есть, в Neo4j нет | Нет структурной синхронизации; карта не создаёт её сама |
| Правило памяти написано, агент не использует её | Проверьте доступный инструмент и фактический вызов поиска |
| Обновление не удалось | Смотрите предупреждение и время последнего снимка; не выдавайте старую версию за свежую |

## Перед передачей другим

Публикуйте только исходники, инструкции и вымышленные примеры. Исключите `private/`, экспорты, пароли, `.env`, логи и резервные копии. Проверьте содержимое архива, а не только `.gitignore`. Новый пользователь должен иметь возможность запустить демо без ваших файлов и аккаунта.
