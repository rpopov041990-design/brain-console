# ChatGPT → личная память: контролируемый перенос

**Это маршрут и формат подготовки, не уже работающий автоматический импортёр.** Brain Console не читает аккаунт ChatGPT. В публичном комплекте нет переписок или сохранённых воспоминаний автора.

## 1. Разделите источники

- Выбранные чаты: решения, договорённости, задачи и подтверждённые факты.
- Сохранённая память ChatGPT: устойчивые предпочтения и контекст, проверенные владельцем отдельно.
- Правила работы: согласованные инструкции, а не случайные указания внутри переписки.

OpenAI описывает память как средство сохранения полезного контекста и отличает её от обязательных проектных инструкций: [персонализация ChatGPT](https://learn.chatgpt.com/docs/personalize). Не считайте экспорт чатов полной копией сохранённой памяти. Формат и способ получения данных зависят от доступного интерфейса; точный автоматический способ экспорта здесь не заявлен.

## 2. Получите только согласованные данные

Владелец передаёт локальные копии выбранных чатов или выписки доступным ему способом. Сохранённые воспоминания сверяются отдельно в настройках продукта. Не запрашивайте пароль, cookie, токены сессии или полный доступ к аккаунту ради импорта.

Исходники храните вне публичной папки либо внутри исключённой `private/`. Не открывайте приватные файлы для публикации и не отправляйте их облачной модели без согласования конкретного получателя и состава данных.

## 3. Подготовьте карточки, не весь архив

Одна карточка — одна проверяемая мысль. Минимальный пример **вымышленный**:

```json
{
  "source_system": "chatgpt",
  "source_id": "example-chat-001",
  "source_kind": "selected_chat",
  "title": "Учебный проект: выбор контрольного цвета",
  "observed_at": "2026-01-01T12:00:00Z",
  "summary": "Для учебного проекта выбран цвет индиго.",
  "status": "candidate",
  "owner_approved": false,
  "project_id": "example-project",
  "related_agent_ids": [],
  "supersedes": null
}
```

Для сохранённого воспоминания используйте `source_kind: "saved_memory"`. Укажите источник и дату; не придумывайте отсутствующие сведения. Утверждения ассистента из старого чата не становятся подтверждёнными фактами автоматически. Ключи, контакты и личные подробности, не нужные для задачи, исключите.

## 4. Проверка и запись

1. Покажите владельцу список карточек и будущих связей с проектами/агентами. Ничего не импортируйте до отбора и проверки.
2. Используйте стабильный ключ из системы-источника, ID и отпечатка содержимого. Повторный импорт не должен создавать дубликаты. Храните локальный журнал ID результата и статуса, а не полные тексты в логах.
3. Начните с отдельной группы `chatgpt-private` через штатный инструмент Graphiti. Это предлагаемая изоляция; текущий экран показывает только `codex-pinned` и `codex-global`. **Третий слой и межгрупповые маршруты ещё не реализованы.** Не смешивайте данные с общей памятью только ради их появления на карте.
4. Для появления на карте сначала реализуйте отдельный выбираемый слой с фильтрами группы на сервере, поиском, карточками источника и тестом отсутствия смешения. Не заменяйте фильтры запросом ко всей базе.
5. Связывайте с агентами по проверенным ID и назначению, не только похожим именам. Межгрупповые связи разрешаются отдельно; ссылки на источник не дают доступа к сырой переписке.
6. Изменившиеся сведения помечайте как заменённые с сохранением происхождения. Не перезаписывайте более свежий факт старым экспортом.

## 5. Что доказывает успешный перенос

- Согласованные карточки сопоставлены с фактическими ID эпизодов/фактов; очереди завершены.
- Контрольный поиск возвращает нужный источник и актуальную версию.
- Повторный импорт той же партии не меняет количество сущностей без причины.
- Частичный сбой оставляет понятный список успешных/неуспешных записей; повторяется только безопасная часть.
- Новый слой карты показывает только разрешённые данные и обновления.
- Демо и архив для GitHub не содержат ничего из этой партии.

Откат планируется до записи: резервная копия штатным способом, журнал ID конкретной партии, точечное удаление только после проверки общего использования сущностей. Слепое удаление всех соседей эпизода может уничтожить общие знания.
