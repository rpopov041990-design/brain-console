# Brain Console · Мозг

> **ТЕСТОВАЯ ВЕРСИЯ / EXPERIMENTAL PREVIEW.** Возможны ошибки. На macOS Apple Silicon проверены локальное демо, 3D-рендер и сборка. Для macOS Intel и Windows x64 добавлена проверка сборки/тестов в GitHub Actions; результат конкретного запуска смотрите ниже. Проверка CI не означает проверку аппаратного WebGL на всех видеокартах. Не используйте как единственное хранилище важных данных.

[![Compatibility](https://github.com/rpopov041990-design/brain-console/actions/workflows/compatibility.yml/badge.svg)](https://github.com/rpopov041990-design/brain-console/actions/workflows/compatibility.yml)

**Агенты, навыки и связи — в единой интерактивной 3D-вселенной.**

![Анатомический контур](public/brain.png)

Русскоязычная локальная карта с двумя темами: «Космос» и «Мозг». В космосе агенты, записи и реальные связи — объекты общей 3D-сцены, а не диаграмма поверх картинки. Категории подсвечиваются как созвездия, но не разделяют пространство. Новые данные не сдвигают существующие узлы.

## Что внутри

- Единая WebGL2-вселенная с вращением, перспективой, выбором планет и подлётом к объекту.
- Альтернативная анатомическая карта мозга, доступная также без WebGL2.
- Карточки агентов, команды, приоритеты и профили мышления.
- Поиск и таблица связей с указанием источника.
- Отдельные слои проектной памяти и общего развития.
- Обновление структуры каждые 30 секунд при видимой вкладке.
- Демо из шести **вымышленных** агентов — без аккаунтов, ключей и базы.
- Опциональное чтение собственного графа Graphiti/Neo4j и реестра.

Карта визуализирует данные, но не запускает агентов, не обучает модель и не создаёт знания автоматически. Светящийся контур — оформление, не измерение активности.

## Быстрый старт

Требуются Node.js 24, npm и Python 3.10+.

```sh
npm ci --ignore-scripts
npm run build
python3 server.py
```

Откройте **http://127.0.0.1:8770**. Остановка: Ctrl+C. В деморежиме Python использует только стандартную библиотеку; приложение не читает домашнюю папку, историю Codex или реальные базы.

### Intel, Apple Silicon и Windows

Сервер написан на Python, интерфейс — на JavaScript/WebGL2: обязательных ARM-, Metal- или Homebrew-компонентов нет. Для Intel устанавливайте **x64**-версию Node.js и Python, для Apple Silicon — **arm64**. [Официальные дистрибутивы Node.js 24](https://nodejs.org/en/download/archive/v24) содержат macOS x64 и Windows x64. Не переносите `node_modules` между архитектурами — выполняйте `npm ci --ignore-scripts` на целевой машине.

На Windows команды запуска:

```powershell
npm ci --ignore-scripts
npm run build
py -3 server.py
```

Для 3D требуется современный браузер, поддерживающий [WebGL2](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext), и совместимый графический драйвер. Старые Intel Mac с неподдерживаемой Node.js ОС и видеокарты без WebGL2 не гарантируются. Если 3D недоступен, переключитесь на «Мозг», «Агенты» или «Связи». При медленной графике отключите автовращение и «Все связи».

CI проверяет Node/Python, геометрию сцены, демо-сервер и production-сборку на macOS Intel, macOS ARM, Windows x64 и Linux x64. **Аппаратный рендер на Intel и Windows пока требует пользовательской проверки.**

### Управление вселенной

- Тянуть мышью — вращать; Shift или «Сдвигать» — перемещать камеру.
- Колесо или ± — приблизить; стрелки клавиатуры — повернуть.
- Нажать планету — выбрать агента; «К объекту» — подлететь; «Общий вид» — сбросить камеру.
- «Подсветить созвездие» выделяет категорию без перегруппировки.
- Автовращение включается отдельно, останавливается при ручном действии и в скрытой вкладке; учитывает системное уменьшение движения.

Звёздная пыль — оформление, не данные и не индикатор работы агентов. Сцена показывает текущий структурный слой; для поиска остальной памяти есть вкладка «Память».

## Собственные данные — только явно

Начните с [маршрута создания и проверки памяти](MEMORY_SETUP.md): он разделяет случаи «память уже есть» и «создаём с нуля». Для выбранных чатов и воспоминаний ChatGPT есть [отдельный маршрут переноса](CHATGPT_IMPORT.md). Это инструкции для собственной системы, не доступ к данным автора.

Демо не требует Neo4j. Для опционального live-режима:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install 'neo4j>=5.26,<7'
```

Задайте `NEO4J_URI`, `NEO4J_USER`, `NEO4J_DATABASE` и `NEO4J_PASSWORD` в окружении своего процесса. Пароль не передавайте в командной строке, не записывайте в репозиторий и не присылайте в issue. Предпочтителен отдельный пользователь базы только для чтения.

```sh
python3 server.py --live --registry /your/private/task-personas.json
```

Опционально: `--pins /your/private/state.json`, где `pinned-thread-ids` — массив ID. Автоматического поиска профилей на компьютере нет. Ожидаемая схема реестра описана в [DATA_FORMAT.md](DATA_FORMAT.md).

Адаптер ожидает группы `codex-pinned` и `codex-global`, узлы с `uuid`/`thread_id` и типы из `server.py`. Это **не универсальный импорт любой базы Neo4j**. Подключение проверяйте на своей тестовой базе; приватная конфигурация автора не входит в комплект.

## Безопасность и ограничения

Сервер слушает только `127.0.0.1`, не имеет маршрутов записи и проверяет Host/Origin. Авторизации для интернет-доступа нет: не пробрасывайте порт и не ставьте публичный прокси перед live-режимом. Данные защищены от случайной внешней публикации архитектурой запуска, но локальные приложения с доступом к компьютеру могут читать локальный HTTP.

Данные и секреты не включены. `private/`, `.env`, логи, зависимости и сборки исключены из Git. Не складывайте персональные данные в другие отслеживаемые файлы.

Профили и граф могут расходиться — интерфейс отмечает отсутствующие узлы. Сходные связи разных источников могут отображаться отдельно. Поиск памяти идёт по названиям, не по сырым чатам. Дополнительные связи загружаются по кнопке. Ограничения выборки: 10000 узлов, 20000 связей. Тема «Мозг» показывает максимум 800 линий; космос — актуальные отношения полученного снимка при включённом «Все связи».
