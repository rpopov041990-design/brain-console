# Brain Console · Мозг

> **ТЕСТОВАЯ ВЕРСИЯ / EXPERIMENTAL PREVIEW.** Возможны ошибки. На macOS проверены локальное демо, сборка и чтение базы автора. Windows и установка на чистом компьютере пока не проверены. Не используйте как единственное хранилище важных данных. Обратная связь приветствуется.

**Агенты, навыки и связи — в одном интерактивном мозге.**

![Анатомический контур](public/brain.png)

Русскоязычная локальная карта с постоянной формой мозга: выбирайте агента, изучайте его профиль и навыки, просматривайте направления связей и источники. Новые данные не сдвигают существующие узлы.

## Что внутри

- Анатомический фон и интерактивные узлы поверх него.
- Карточки агентов, команды, приоритеты и профили мышления.
- Поиск и таблица связей с указанием источника.
- Отдельные слои проектной памяти и общего развития.
- Обновление структуры каждые 30 секунд при видимой вкладке.
- Демо из шести **вымышленных** агентов — без аккаунтов, ключей и базы.
- Опциональное чтение собственного графа Graphiti/Neo4j и реестра.

Карта визуализирует данные, но не запускает агентов, не обучает модель и не создаёт знания автоматически. Светящийся контур — оформление, не измерение активности.

## Быстрый старт

Требуются Node.js 24, npm и Python 3.10+.

```sh
npm ci --ignore-scripts
npm run build
python3 server.py
```

Откройте **http://127.0.0.1:8770**. Остановка: Ctrl+C. В деморежиме Python использует только стандартную библиотеку; приложение не читает домашнюю папку, историю Codex или реальные базы.

## Собственные данные — только явно

Начните с [маршрута создания и проверки памяти](MEMORY_SETUP.md): он разделяет случаи «память уже есть» и «создаём с нуля». Для выбранных чатов и воспоминаний ChatGPT есть [отдельный маршрут переноса](CHATGPT_IMPORT.md). Это инструкции для собственной системы, не доступ к данным автора.

Демо не требует Neo4j. Для опционального live-режима:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install 'neo4j>=5.26,<7'
```

Задайте `NEO4J_URI`, `NEO4J_USER`, `NEO4J_DATABASE` и `NEO4J_PASSWORD` в окружении своего процесса. Пароль не передавайте в командной строке, не записывайте в репозиторий и не присылайте в issue. Предпочтителен отдельный пользователь базы только для чтения.

```sh
python3 server.py --live --registry /your/private/task-personas.json
```

Опционально: `--pins /your/private/state.json`, где `pinned-thread-ids` — массив ID. Автоматического поиска профилей на компьютере нет. Ожидаемая схема реестра описана в [DATA_FORMAT.md](DATA_FORMAT.md).

Адаптер ожидает группы `codex-pinned` и `codex-global`, узлы с `uuid`/`thread_id` и типы из `server.py`. Это **не универсальный импорт любой базы Neo4j**. Подключение проверяйте на своей тестовой базе; приватная конфигурация автора не входит в комплект.

## Безопасность и ограничения

Сервер слушает только `127.0.0.1`, не имеет маршрутов записи и проверяет Host/Origin. Авторизации для интернет-доступа нет: не пробрасывайте порт и не ставьте публичный прокси перед live-режимом. Данные защищены от случайной внешней публикации архитектурой запуска, но локальные приложения с доступом к компьютеру могут читать локальный HTTP.

Данные и секреты не включены. `private/`, `.env`, логи, зависимости и сборки исключены из Git. Не складывайте персональные данные в другие отслеживаемые файлы.

Профили и граф могут расходиться — интерфейс отмечает отсутствующие узлы. Сходные связи разных источников могут отображаться отдельно. Поиск памяти идёт по названиям, не по сырым чатам. Дополнительные связи загружаются по кнопке. Есть явные ограничения выборки: 10000 узлов, 20000 связей и 800 линий на карте.

Создайте Issue с версией ОС, Python и Node.js, шагами воспроизведения, ожидаемым и фактическим результатом. Прикладывайте только обезличенные ошибки и скриншоты демо. В Windows вместо `python3 server.py` обычно используется `py server.py`. Для PowerShell активация окружения: `.venv\Scripts\Activate.ps1`; если политика исполнения её блокирует, не отключайте защиту — вызывайте `.venv\Scripts\python.exe` напрямую. Эквивалент команд macOS `source` в Windows не используется.
