# Компоненты и визуальные материалы

- React / React DOM: зависимости npm; сведения о лицензиях находятся в соответствующих пакетах.
- Vite и его зависимости: инструменты сборки, версии зафиксированы в package-lock.json.
- Neo4j Python Driver: опциональная зависимость live-режима, не поставляется внутри архива.
- public/brain.png: изображение, сгенерированное ИИ для этого проекта; не медицинская иллюстрация и не фактический граф. Исходный пользовательский референс в комплект не входит.
- Космическая тема: собственный WebGL2-рендер и процедурные частицы без сторонних фотографий, моделей планет, текстур или нового 3D-движка. Частицы оформления не являются записями памяти.

Собственный код и предоставляемый визуальный материал распространяются по MIT в пределах имеющихся прав. При распространении сборок сохраняйте применимые уведомления лицензий сторонних пакетов. Названия продуктов принадлежат их владельцам; аффилированность не подразумевается.
